# ClingProject — Cling Info Tech Website Clone

A modern and responsive frontend recreation of the **Cling Info Tech** website, developed as part of an **internship assessment project**.

The project focuses on recreating the original website's layout, visual design, navigation, sections, responsive behavior, and overall user experience using modern frontend technologies.

> **Note:** This project is a frontend recreation/clone created for educational and internship assessment purposes. It is not the official Cling Info Tech website.

## 📌 About The Project

The objective of this internship assessment was to recreate the **Cling Info Tech** website as closely as possible while building the interface from scratch using React and modern frontend development practices.

The recreated website includes major sections such as:

* Hero Section
* Company Introduction
* Statistics
* Global Presence
* Diverse Clientele
* Company Story
* Vision & Mission
* Services
* Current Technology Focus
* 3D Animation Section
* AI/ML Section
* Leadership Team
* Testimonials
* Contact Form
* Footer
* Responsive Navigation

The original website presents Cling Info Tech as an IT solutions company providing services including web development, mobile application development, digital marketing, ERP solutions, and custom IT solutions.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

### 2. Navigate to the project

```bash
cd ClingProject
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173/
```

---

## 🖥️ Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
